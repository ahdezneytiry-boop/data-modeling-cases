历次数学建模竞赛的代码存档，覆盖多个主流赛事与常见题型，方便回顾与复用。

## 目录

| 目录 | 赛事 | 内容 |
|---|---|---|
| `mathorcup-2025/` | 2025 MathorCup 数学应用挑战赛（妈妈杯） | D 题求解代码 |
| `mathorcup-2026/` | 2026 MathorCup（妈妈杯） | MC 题：建模与可视化 |
| `apmcm-2025/` | 2025 APMCM 亚太地区大学生数学建模竞赛 | 数据预处理、多疾病分析（XGBoost/逻辑回归/随机森林）、筛查策略 |
| `huashubei-2025/` | 2025 华数杯数学建模竞赛 | 问题 1–4 求解代码 |
| `cumcm-2026-C/` | 2026 全国大学生数学建模竞赛（国赛） | C 题 Q4 交付：源代码 + 核验脚本 + 章节草稿 |
| `mcm-2026/` | 2026 MCM/ICM（美赛） | 数据预处理与 Q1–Q4 求解 |
| `dawanbei/` | 大湾杯（粤港澳金融数学建模） | 求解脚本 |
| `ahp/` | 层次分析法 | Python / MATLAB 两种实现 |

## 说明

- 论文、承诺书等含个人信息的文档未包含在本仓库。
- 竞赛数据文件因版权与隐私原因未包含；代码中标注了所需数据的字段结构。
- 部分代码为比赛期间的即兴脚本，命名较随意，请以"能跑出论文结果"为准。
