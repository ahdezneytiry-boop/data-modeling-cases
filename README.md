面向真实业务场景的数据建模与优化求解代码集合，覆盖医疗筛查、物流调度、金融分析等场景，包含数据预处理、模型构建、可视化与结果核验全流程。

## 案例目录

| 目录 | 场景 | 内容 |
|---|---|---|
| `2025-medical-screening/` | 医疗筛查 | 多疾病风险预测（XGBoost / 逻辑回归 / 随机森林）与筛查策略 |
| `2025-d/` | 调度优化 | 问题一模型优化求解 |
| `2025-problems/` | 综合建模 | 多问求解（问题 1–4） |
| `2025-finance/` | 金融分析 | 求解脚本集 |
| `2026-mc/` | 综合建模 | 建模与可视化 |
| `2026-c/` | 优化求解 | 源代码 + 核验脚本 + 结果说明 |
| `2026-international/` | 综合建模 | 数据预处理与 Q1–Q4 求解 |
| `ahp/` | 决策分析 | 层次分析法 Python / MATLAB 实现 |

## 说明

- 原始数据文件因版权与隐私原因未包含；代码中标注了所需数据的字段结构。
